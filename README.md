# Kärcher Robotics Coding Challenge
Path Length - Cleaned Area - Traversal Time

A cleaning robot has driven through a building and recorded where it went. You get that recording, the
robot's footprint, and the geometry of its cleaning gadget. We would like to know three things about the
run: 
1. how far it drove, 
2. how much floor it actually cleaned, and 
3. how long it would take to drive that path at a realistic speed.
